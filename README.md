# OBE Evaluation Report Generator

An automated Outcome-Based Education evaluation application for generating CLO attainment analysis, assessment analysis, student performance analysis, CQI action plans, charts, and downloadable Word and Excel reports.

## Features

- Course Outline upload
- OBE Excel upload
- CLO attainment analysis
- Assessment-to-CLO mapping
- Student performance analysis
- CQI Action Plan
- OBE charts
- Word report generation
- Excel report generation

## Source Hierarchy

Course Outline = authoritative source for official course information and CLO wording.

Excel file = authoritative source for numerical assessment and student performance data.

## Privacy

Do not upload student-identifiable Excel files to a public GitHub repository.
